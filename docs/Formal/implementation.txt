### Implementation approach

1. Introduce configurable contribution categories.
2. Add transaction lifecycle states:
   - Pending
   - Confirmed
   - Reconciled
   - Reversed
3. Do not silently edit or delete confirmed transactions.
4. Use reversal and adjustment records.
5. Require a reason for corrections.
6. Record old value, new value and actor.
7. Add duplicate-reference detection.

- TransactionCategory

- Reconciliation

- AccountingPeriod

### Implementation approach

2. Record income and expenditure separately.
3. Define accounts such as:
   - Cash
   - Bank
   - M-Pesa
   - Welfare fund
   - Project fund
4. Use immutable transaction records.
5. Calculate balances from ledger entries.
6. Require supporting evidence for selected expenditure categories.
7. Add approval rules for high-value transactions if required.
8. Close accounting periods to prevent unauthorized historical changes.

## 3.3 Payment reconciliation

### Missing functionality

- Unmatched payments queue
- Manual member matching
- Duplicate detection
- Reconciliation notes
- Bank/M-Pesa comparison
- Reconciliation report

### Implementation approach

4. Allow Treasurer to assign a member and category.
5. Require notes for manual reconciliation.
6. Audit every match and correction.
